# 🎤 DeepSeek Voice Assistant

Голосовой помощник на базе DeepSeek API с полным голосовым управлением.  
**Без кнопок, только голос.**

Автор: **Дмитрий Хайбулин**

---

## ✨ Возможности

- 🎙️ **Активация голосом** — скажите **«Дипсик»** (короткий звуковой сигнал подтвердит пробуждение)
- 🧠 **Долгие паузы** — можно думать до 20 секунд, приложение ждёт
- 📨 **Ручная отправка** — скажите **«Отправляй»** для мгновенной отправки вопроса
- ⏱️ **Автоотправка** — приложение само отправит вопрос после заданной паузы (настраивается 3–20 сек)
- 🔊 **Голосовые ответы** — DeepSeek отвечает голосом через динамик или наушники
- 🔑 **Сохранение API-ключа** — ключ хранится локально на устройстве
- 🌙 **Работа в фоне** — приложение постоянно слушает триггерную фразу

---

## 🚀 Как использовать

1. **Получите API-ключ** на [platform.deepseek.com](https://platform.deepseek.com)
2. Откройте приложение
3. Вставьте API-ключ и нажмите **«Сохранить ключ»**
4. Разрешите доступ к микрофону
5. Скажите **«Дипсик»** → дождитесь короткого писка
6. Задайте вопрос (можно делать паузы, думать)
7. Для отправки скажите **«Отправляй»** или просто замолчите на 10 секунд
8. Получите голосовой ответ

## 📱 Установка

### Сборка APK

1. Установите [Node.js](https://nodejs.org/)
2. Установите Bubblewrap: `npm install -g @bubblewrap/cli`
3. Клонируйте репозиторий: `git clone https://github.com/ваш-аккаунт/deepseek-assistant.git`
4. Инициализируйте Bubblewrap: `bubblewrap init --manifest https://ваш-username.github.io/deepseek-assistant/manifest.json`
5. Соберите APK: `bubblewrap build`

### Либо через PWABuilder

1. Перейдите на [PWABuilder.com](https://pwabuilder.com)
2. Вставьте ссылку: `https://ваш-username.github.io/deepseek-assistant`
3. Нажмите «Build» → скачайте APK
